# Exploring Manipal - Interactive Leaflet Map

## About

This project is an interactive webpage created using R Markdown and the Leaflet package in R.

The webpage features an interactive map of Manipal with markers for selected locations, including Manipal Institute of Technology, Manipal Lake, and End Point.

- OpenStreetMap
